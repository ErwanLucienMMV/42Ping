# ft_ping

C implementation of the IPv4 ICMP Echo utility for the supplied 42 subject.

The implementation and detailed walkthrough are in progress. Build on Linux
with `make`; the executable is named `ft_ping`.

The supplied evaluation sheet explicitly requires a Linux virtual machine,
kernel newer than 3.14, and root privileges. Docker is useful for development
and testing, but that wording should not be presented as permission to replace
the formal evaluation VM.
